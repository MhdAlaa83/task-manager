# task-manager
📌 Project Summary

Task Manager is a lightweight web application built with Laravel that allows users to efficiently manage their daily tasks. It provides a simple and elegant interface to create, update, delete, and search tasks, making it a practical demonstration of CRUD (Create, Read, Update, Delete) operations combined with a basic search feature.

📖 Project Description

The Task Manager system is designed as a mini productivity tool where users can:

Create Tasks: Add new tasks with a title, description, status, and optional due date through a clean and structured form.

View Tasks: Browse all tasks on a responsive index page styled with elegant cards for a modern look.

Search Tasks: Quickly find tasks by name using the search bar integrated on the index page.

Update Tasks: Edit existing tasks from a dedicated edit page and keep track of changes.

Delete Tasks: Remove tasks directly from the task list with a simple action button.

The project emphasizes simplicity, usability, and visual appeal. It uses Laravel’s MVC architecture for clean code organization, Eloquent ORM for database interactions, Blade templating for the front-end, and Tailwind CSS for modern styling with a glassmorphic card design.

Additionally, the project includes factories and seeders that generate dummy tasks, making it easy to test the application and demonstrate functionality without manual input.
